# Vector 3D

3Dのメッシュ、曲線、カメラ、可視判定を扱い、最終描画を同じSlugベクター描画経路へ渡します。
`SLUGIA_ENABLE_3D=ON` が必要です。通常の2D APIと同じ `DrawList` に混在できます。

## 起動と操作

専用デモは `slugia-3d`、Windowsのビルド出力は `build/Release/slugia-3d.exe` です。
通常のExampleの「Vector 3D」ページも共通のシーン描画に接続しています。

- 左ドラッグでシーンを回転、ホイールで拡縮、物体をクリックして選択します。
- XYZ回転、透視の強さ、深度、陰影、稜線、透明表示を操作できます。
- UIカードは独立した回転を持ち、投影されたボタンをクリックできます。
- `.obj` / `.slug3d` をドロップすると読み込み、全体が見える大きさへ調整します。
- 操作のないフレームは保持した3D描画を再利用します。

```powershell
.\build\Release\slugia-3d.exe
.\build\Release\slugia-3d.exe --asset examples/vector3d_demo.slug3d
```

## 共通シーン

複数の物体を一つの `drawScene3D` に渡すと、物体同士を含む前後関係を解決します。
個別の `drawMesh3D` 呼び出しは、それぞれ独立したシーンになります。

```cpp
auto box = slugia::makeBoxMesh3D({48,48,48});
auto sphere = slugia::makeUvSphereMesh3D(50,32,16);
std::array<slugia::SceneObject3D,2> objects{};
objects[0].mesh = &box;
objects[0].id = 1;
objects[0].style.shaded = true;
objects[1].mesh = &sphere;
objects[1].id = 2;
objects[1].transform.translation = {65,0,20};
objects[1].style.fill = slugia::Paint::solid(slugia::Color::fromRgb8(0x52d0b1));
objects[1].style.shaded = true;

slugia::Mesh3DView view;
view.origin = {400,300};
view.camera.position = {0,0,-700};
view.camera.focalLength = 700;
view.transform.rotation = {0.2f,0.4f,0.0f};
const auto stats = slugia::drawScene3D(draw,objects,view);
const auto hit = slugia::pickScene3D(pointer,objects,view);
```

メッシュの参照は `drawScene3D` / `pickScene3D` の呼び出し中に有効である必要があります。
描画コマンドは変換済みのベクター形状を所有するため、その後GPU描画が終わるまで元メッシュを
保持する必要はありません。`drawScene3D` は構築を終えてから呼び出し元のDrawListへ追加し、
可視判定・分割予算に達したときは例外にします。

## カメラと座標

ローカル +X が右、+Y が下、カメラの +Z が前方です。回転はXYZ Euler、単位はradです。
`AffineTransform3D` で親子の変換を合成でき、反転・非等方scaleも可視判定に反映します。

- `perspective=0` は平行投影、`1` は透視投影です。中間値も連続的に変化します。
- `focalLength` は焦点距離の画素換算値です。0は従来のUI座標互換としてカメラZから決めます。
  初期カメラはZ=-520なので、Z=0で1単位がおよそ1画素になります。
- `rotation` はカメラからworldへの姿勢です。
- `nearPlane` / `farPlane` の内側だけを描きます。面や辺が境界を跨ぐ場合は交点で切断します。

`projectPoint3D`、`projectPlane3D`、`unprojectPlane3D` は同じ投影式を使用します。
選択判定も同じカメラと変換に対して行い、手前の面のID、三角形、位置、法線、barycentric座標を返します。
`pickScene3D` はmesh faceを対象とし、curve単体のhit testは行いません。

## 可視判定、透明度、継ぎ目

面の位置・深度を投影面上の式として保持し、手前の面による隠れ部分を切り取ります。
交差する面も部分ごとに解決します。候補の探索には画面上のBVHを使い、凸メッシュには
自身の面同士が重ならない経路を用います。辺と曲線も同じ面群で遮蔽します。

単色はまとめた輪郭で描き、複数材質や陰影の境界は共通coverage maskと色の加算で合成します。
三角形を個別に通常のalpha blendすることで生じる暗い継ぎ目を防ぎます。
追加の画面全体の画像バッファやCPU読み戻しは不要です。

透明面は重なりと等深度線で分割し、局所的な奥行き順に合成します。
処理量には `Scene3DConfig::maxFragments`、`maxOcclusionTests` の上限があります。
同一位置に異なる材質の面を完全に重ねた場合の優先順位は、入力順に依存します。

`shaded` は面法線と方向光を使うフラットな陰影です。`trianglePaints` があれば面ごとの材質を使い、
なければ `Mesh3DStyle::fill` を使います。PBRやUV画像テクスチャのAPIではありません。

## 曲線

`Curve3D` はBezier、polyline、正の重みを持つNURBSを保持します。
`prepareCurve3D` は制御点を残したまま、NURBSの各区間を有理Bezierへ変換します。
制御点を編集したら再度呼んでください。degreeは1〜15です。

表示時は現在の投影に合わせて適応分割し、`curveTolerancePx` によって画素単位の許容誤差を設定します。
近接面の切断と、メッシュによる隠線処理も適用します。細かさをファイルに焼き込む必要はありません。
線幅はフレームバッファ画素で指定します。準備・分割・出力の予算を超える入力は例外にします。

## 3D UI平面

```cpp
slugia::DrawList panel;
panel.setClip({-150,-70,300,140});
panel.roundedRect({-150,-70,300,140},12,paint);
panel.text("Vector text",{-120,-30,240,30},style);
slugia::drawPlane3D(draw,panel,planeView);
auto localPointer = slugia::unprojectPlane3D(pointer,planeView);
```

文字・図形をビットマップへ焼かず、射影変換と透視補間で描きます。
ローカルclipと出力先のclipをそれぞれ適用します。平面の入力は逆変換して通常の2D領域で判定できます。
このAPIはDrawListの描画順で合成するUI平面です。メッシュ群の可視判定に自動参加する面ではありません。
射影済みDrawListの入れ子は拒否します。

## ファイルと保持

`loadScene3D(path)` はOBJとSlug3D v1を読みます。OBJの凹polygonはear clippingし、非平面polygonは
支配平面への投影で三角形へ下ろします。不正index、縮退、非多様体、予算超過は診断します。
OBJは位置とpolygonを読み、MTL / UV画像texture / authored normalのimportは提供しません。
Slug3Dは元polygon、curveの制御点、重み、材質、world変換、sharp edgeを保持します。

Blenderからは `tools/blender_slug3d_export.py` を使います。bevel/extrudeがあるcurveは、
元curveと評価済みメッシュの両方を出力し、表示には後者を利用します。

変わらないシーンは、生成したDrawListを `createRetainedDrawList` で保持できます。
coverage maskと材質の合成境界も保持されます。カメラや形状が変わる場合は3D可視判定から作り直してください。

## 生成・準備API

`makeBoxMesh3D`、`makeOctahedronMesh3D`、`makeUvSphereMesh3D`、`makeCylinderMesh3D`、`makeConeMesh3D` がmeshを作ります。
size引数はboxのhalf extent、sphereのradius、cylinder / coneのradiusとhalf heightです。
任意のvertices / trianglesを作った場合は `prepareMesh3D` でedge・隣接・非多様体を検査します。
`triangulateFace3D` はindexed polygonを三角形へ変換します。
`drawSphere3D` / `drawCylinder3D` / `drawCone3D` はVectorSolid3DStyleを使う直接描画の補助APIです。

`Mesh3DImportLimits` は既定64 MiB、1,048,576 vertices、2,097,152 triangles、face当たり65,536 verticesです。
procedural meshも1,048,576 verticesを上限に割当前に検査します。
`Scene3DConfig` の既定はfragment65,536、occlusion test4,000,000、curve subdivision65,536、curve誤差0.1 pxです。
陰影はlightDirection / ambient / diffuseで指定します。`Scene3DStats` は処理triangle・clip・可視fragment・
occlusion test・出力command・curve segment数を返します。
